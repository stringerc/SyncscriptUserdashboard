## Executive Summary

Current digital product distribution is plagued by single-platform fragility and deliverable mismatch. Traditional sellers either post raw ZIP files onto Gumroad where there is zero organic discovery, or manually upload Canva templates to Etsy without cross-monetizing on publishing (Amazon KDP) or merchandise (Redbubble).

This design details the **Omni-Asset Product Ecosystem**: a unified intellectual property (IP) engine that autonomously compiles into four native asset classes:
1. **Direct Software/SOP Archives (ZIP):** Gumroad, Payhip, Sellfy, Ko-fi
2. **Interactive Cloud Templates & Vector Bundles (PDF/Links):** Etsy, Creative Market
3. **Physical Bound Paperbacks (Print-Ready PDF):** Amazon KDP
4. **High-Resolution Vector Merch (300 DPI Transparent PNG):** Redbubble, Society6

The initial champion product ecosystem is **The Sovereign Real Estate Acquisition & Branding System** (derived from Product #3 in our catalog), representing the single highest-converting digital category across organic algorithmic search engines globally.

### 1. Instant KDP Interior & Dynamic Cover Wrap Generation via Typst
Instead of manual InDesign formatting, a 3-second build script compiles the entire 124-page interior and dynamically calculates the mathematical spine width for the cover wrap:
```bash
# 1. Compile 124-page guided interior PDF (8.5" x 11")
typst compile storefront/generators/kdp-real-estate-interior.typ storefront/build/kdp-interior-8.5x11.pdf

# 2. Compile dynamic wraparound cover PDF (Back + Spine + Front + 0.125" Bleed)
# Spine width = 124 pages * 0.002252" = 0.2792"; Total width = 8.5 + 0.2792 + 8.5 + 0.25 = 17.5292"
typst compile --input pages=124 storefront/generators/kdp-real-estate-cover.typ storefront/build/kdp-cover-wrap.pdf
```
- **ISBN & Compliance:** Uses KDP's free ISBN model with pen name attribution ("Christian Sterling") and automated AI-assisted declaration checkbox.

### 2. Canva Token Access Sheet & Printable PDF Deliverables
An automated HTML-to-PDF pipeline (via headless Chrome / Puppeteer) renders the customer access sheet containing:
- Authenticated Canva template share links (150+ customizable pages).
- 2 instant printable high-res PDF bonuses: *Open House Client Sign-in Sheet* and *Listing Presentation Preparation Checklist*.

### 3. Redbubble "Copy Settings" Template Automation
To prevent awkward cropping on 60+ merchandise types, the Redbubble automation uses Redbubble's native "Copy Settings" flow from a configured master template, updating the artwork, title, tags, and description in a single reliable operation.

### 4. Interactive Human-in-the-Loop CDP Supervisor (`pauseAndPrompt`)
If a marketplace triggers a CAPTCHA, Cloudflare challenge, or 2FA prompt, the runner does not crash. It triggers a Cortex desktop notification and voice cue (`"Operator intervention needed for Etsy verification"`), pauses execution on the visible browser tab, and resumes automatically once the challenge is solved.

### 5. Automated Asset Packaging (`npm run build:omni-package`)
A single CLI script packages:

- `dist/kdp/interior-8.5x11.pdf` & `dist/kdp/cover-wrap.pdf`

### Anti-Bot & Session Resilience Strategy
1. **Persistent Browser Context:** Uses the existing local Chrome instance (`http://127.0.0.1:9222`) where user logins (Etsy, Amazon, Redbubble) are logged in once with active 2FA cookies. No headless bot flags or cloud IPs.
2. **Humanized Keystroke & Mouse Jitter:** Emulates realistic human typing cadence (80–140ms per key) and natural Bezier mouse trajectories across file-upload dropzones.
3. **Daily Cadence Restraint:** Matches platform rate limits:
   - Gumroad: 2–3 products/day
   - Etsy: 1 new listing every 48 hours (to build seller quality score)
   - Amazon KDP: 1 book every 72 hours (to pass metadata compliance review)
