# Real Estate AI Listing Kit

100+ production-grade prompts for real estate agents — descriptions, follow-ups,
CMAs, negotiations, reviews, social content, prospecting, transactions, and
nurture. Plus the "AI tells" list and rewrite checklist that keep output human.

## How to use

1. Start with Section 1 (Listing Descriptions) — that's the core product.
2. Fill in [brackets] with your property/client details.
3. Run every output through the Rewrite Checklist at the end.
4. Sections 11-15 cover transactions, open houses, niche markets, database
   nurture, and rapid-fire one-offs.

## What's inside

- 45 numbered prompts across 15 categories
- 45 rapid-fire fill-in-the-blank prompts (Section 15)
- AI-tell phrase list (words/phrases that scream "ChatGPT wrote this")
- Rewrite checklist for quality control

Total: 90+ prompts. Built for working agents, not prompt tourists.
