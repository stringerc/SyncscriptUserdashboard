# Real Estate AI Listing Kit — Prompt Pack v1

100+ prompts for listings that convert. Organized by job. Each prompt is written to produce MLS-ready, human-sounding output — not generic AI filler.

**How to use:** Copy any prompt, replace [BRACKETED] fields with your details, paste into ChatGPT/Claude/your AI tool. For best results, paste the property's actual details (beds, baths, sqft, neighborhood, recent upgrades, price) rather than asking the AI to invent them.

---

## 1. Listing Descriptions (the core product)

**Prompt 1.1 — The Conversion Description**
```
Write a real estate listing description for this property that sounds like a top-producing agent wrote it — warm, specific, and benefit-focused. NOT generic AI filler.

Property: [address, beds, baths, sqft, year built, neighborhood]
Key features: [list 3-5 standout features]
Recent upgrades: [list upgrades if any]
Price: $[price]
Target buyer: [first-time buyer / move-up / investor / downsizer]

Rules:
- Open with the lifestyle benefit, not the specs
- Weave in the neighborhood's character (not just "great location")
- End with a soft CTA ("Schedule your private tour this week")
- 150-200 words, no bullet points, no exclamation marks
- Avoid words: "boasts," "nestled," "oasis," "dream home" — these are AI tells
```

**Prompt 1.2 — The Luxury Description**
```
Write a luxury real estate listing description for a $[price]+ property.

Property: [address, beds, baths, sqft, lot size]
Standout features: [pool, view, smart home, finishes, etc.]
Neighborhood: [prestigious area name]

Rules:
- Lead with the aspirational lifestyle, not the square footage
- Use sensory language (light, views, finishes) without purple prose
- Mention comparable sales or the "why now" if relevant
- 200-250 words, sophisticated tone, no hype
```

**Prompt 1.3 — The Starter Home Description**
```
Write a listing description for an affordable starter home that makes it feel like the best decision a first-time buyer could make.

Property: [address, beds, baths, sqft, price]
Features: [list features]
Nearby: [schools, parks, transit, amenities]

Rules:
- Emphasize value and potential, not apology for price
- Mention the neighborhood's growth trajectory or community feel
- Address first-time buyer concerns (low maintenance, good schools, commute)
- 150-175 words, encouraging but not desperate
```

**Prompt 1.4 — The Investment Property Description**
```
Write a listing description for an investment property that appeals to buy-and-hold investors.

Property: [address, beds, baths, sqft, current rent if known]
Financials: [purchase price, cap rate if known, monthly expenses]
Location: [neighborhood, rental demand drivers]

Rules:
- Lead with the numbers (cash flow, appreciation potential, demand)
- Mention the rental market context (occupancy, tenant profile)
- Be direct — investors don't want flowery language
- 150-200 words, analytical tone
```

**Prompt 1.5 — The Rewrite System**
```
Rewrite this rough listing description into a polished, conversion-optimized version.

Original description:
[paste your rough description or bullet points]

Property details for context:
[bed/bath/sqft/neighborhood/price]

Rules:
- Keep all factual details accurate — do not invent features
- Fix grammar, tighten sentences, add benefit framing
- Remove AI-sounding phrases ("boasts," "nestled," "oasis")
- Output: one polished paragraph (150-200 words) + 3 alternative opening lines
```

## 3. CMAs & Pricing (the conversations that win listings)

**Prompt 3.1 — The CMA Narrative**
```
Write a comparative market analysis narrative for a seller considering listing their home.

Subject property: [address, beds, baths, sqft, condition]
Comparables: [list 3-5 recent sales with prices and dates]
Market context: [days on market, inventory levels, price trends]

Rules:
- Recommend a listing price with justification
- Explain the market dynamics affecting their home specifically
- Address likely objections ("but my neighbor sold for more")
- Professional but accessible tone — this is for a homeowner, not an appraiser
- 300-400 words + a one-paragraph executive summary
```

**Prompt 3.2 — The Pricing Strategy Email**
```
Write an email to a seller explaining my recommended listing price and strategy.

Property: [address]
Recommended price: $[price]
Their expected price: $[their number]
Key comps: [list 2-3 relevant sales]

Rules:
- Acknowledge their price expectation respectfully
- Present the data objectively (comps, DOM, absorption rate)
- Explain the strategy (price for momentum vs. price for max)
- Offer a clear next step ("let's discuss this Thursday")
- 200-250 words, consultative tone
```

**Prompt 3.3 — The "What If We Priced Higher" Response**
```
Write a response to a seller who wants to price their home above my recommendation.

Property: [address]
My recommended price: $[price]
Their desired price: $[higher price]
Market data: [DOM, inventory, recent price reductions]

Rules:
- Respect their ambition while presenting the data honestly
- Explain the risk of overpricing (longer DOM, stale listing, price cuts signal weakness)
- Offer a middle ground if appropriate ("we could test at $X for 14 days then adjust")
- 150-200 words, firm but not confrontational
```

## 5. Negotiation & Offer Conversations

**Prompt 5.1 — The Multiple Offer Summary**
```
Write a summary of multiple offers for a seller deciding between them.

Property: [address]
Offers received:
- Offer A: $[price], [financing type], [contingencies], [closing date]
- Offer B: $[price], [financing type], [contingencies], [closing date]
- Offer C: $[price], [financing type], [contingencies], [closing date]

Rules:
- Present net proceeds to seller (not just offer price — factor in concessions, repairs, timeline)
- Explain the risk profile of each offer (cash vs. financed, contingencies, appraisal gaps)
- Recommend one with clear reasoning
- Format as a comparison table + a recommendation paragraph
```

**Prompt 5.2 — The Repair Request Response**
```
Write a response to a buyer's repair request after inspection.

Property: [address]
Inspection findings: [list items]
Buyer's request: [what they're asking for]
Seller's position: [what they're willing to do]

Rules:
- Acknowledge the buyer's concerns genuinely
- Present the seller's position with reasoning (safety vs. cosmetic, market norms)
- Offer a compromise if appropriate (credit vs. repair, partial fixes)
- Keep the deal moving — the goal is a win-win, not a victory
- 150-200 words, professional and solution-oriented
```

**Prompt 5.3 — The "We Need More Time" Extension Request**
```
Write an email to a lender or agent requesting a closing extension.

Property: [address]
Current closing date: [date]
Requested extension: [new date]
Reason: [appraisal delay / financing issue / title problem]

Rules:
- Be direct about the reason — no vague excuses
- Offer a solution (the new date, what happens if it can't be met)
- Keep it brief — this is a logistics email, not a negotiation
- 100-150 words, professional and apologetic but not groveling
```

**Prompt 8.3 — The Inspection Report Explainer**
```
Write an explanation of an inspection report for a first-time buyer.

- Translate inspector-speak into plain English
```

```
credit request, or accept). Flag anything that could kill the deal if
ignored. Be honest about what actually matters vs. what inspectors always
flag.
```

## Quick-Reference: The AI Tells to Avoid

These phrases mark AI-generated content — cut them from every output:

- "Boasts" / "boasting" — use "features" or "offers"
- "Nestled" / "nestled in" — use "located in" or "situated in"
- "Oasis" / "paradise" / "dream home" — too generic, too salesy
- "Whether you're..." / "Look no further" — filler openers
- "In today's fast-paced world" — nobody talks like this
- Excessive exclamation marks — one max, usually zero
- "Don't miss out" / "Act now" — pressure tactics backfire
